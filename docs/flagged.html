Repository audit

Starting state

The repository contained a single file: a 4-byte README with the content # X1. There was no source code, no data, no continuous integration, no licence and no documentation to review, so the audit found no irregularities in pre-existing work. The audit trail from that point is kept in COORDINATION.md, which records each task, its owner, its file scope and the sources used.

What was added

A reproducible Python package (src/x1), a static site generator (scripts/build_site.py), a GitHub Actions workflow that deploys the site, and the processed tables that back every published number.
