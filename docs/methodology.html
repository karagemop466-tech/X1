Backtest set-up

  • Regular-season games, 7104 completed in the file (1999–2026). Strategies use 2006 onward, where spreads exist.
  • Spread convention: positive spread = home favored (verified against the dataset's own documentation and the moneyline check above). Home covers if home margin > spread. Equal = push.
  • Pricing: −110 on both sides. Assumption, not verified against any book. Break-even 52.38%.
  • Own model: sequential Elo, updated after each game. Each prediction uses only earlier games. Constants fixed before testing: K = 20, home field = 65 Elo, 25 Elo per point, one-third reversion to 1500 each season. Edge threshold 3 points.
  • Splits: discovery 2006–2015, validation 2016–2020, holdout 2021–2025 (scored once), forward 2026. Nothing was tuned on any split.
  • Multiple testing: Bonferroni across the 10 pre-registered strategies. Note that some strategies are mirrors of others, so the true number of independent tests is smaller. This makes the correction conservative.
  • Team codes: STL, SD and OAK are mapped to LA, LAC and LV for ratings only (franchise relocations). The source uses ARI; NFL.com uses AZ (I-16).

Limits

  • Results depend on the line provider. Until the provider is verified, no result can be treated as evidence (G0).
  • Results are not checked game-by-game against NFL.com for 2006–2025 (I-11). One 2026 game was spot-checked.
  • No injury, depth-chart, snap-count, or player-prop data is used in the backtest yet.
  • Past performance on this data does not show future results.
