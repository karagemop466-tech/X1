## Gate before publishing row-level source data

1. For every source family, record the applicable terms/permission reference, the permitted purpose, retention, transformation, and public-release decision. Until that review is complete, classify the source as **not cleared**; do not infer permission from public accessibility.
2. Keep raw captures and reviewed player-level evidence in an access-controlled store whose endpoint, identity policy, retention, and replay procedure are documented. Store fetch UTC, source URL, content hash, parser/version, and conflict status. This repository currently demonstrates no such private store.
3. Build the public artifact from a reviewed, deny-by-default allowlist. Test the *assembled* `_site/` tree, including HTML-embedded data, JSON, CSV/TSV, archives, and downloads; a link checker alone is not a data-release check.
4. Reconcile existing tracked files, Git history, and prior Pages artifacts with the authorized reviewer before claiming that the split is complete. No history rewrite is proposed here.

**Decision readiness:** the private-data requirement remains blocked. The number that clears it is **zero unclassified or unauthorized source classes in the approved public artifact**, plus a documented, access-controlled destination for the retained raw evidence. The official references are supplied for review; they do not themselves answer the owner-specific licensing or permission question.
