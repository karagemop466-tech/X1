Line-Generation Strategies

Research and strategy design for originating our own NFL lines and useful signals. Strategies span single bets, parlays, and player-prop combos. Every strategy must pass the validation gates before it earns a place on the leaderboard. Performance values are shown blank until a strategy is actually validated — none are fabricated.

Design principle — remove luck, keep skill. A strategy is only useful if its edge is statistically distinguishable from variance. Each strategy below specifies its signal source, where the edge comes from, and exactly how luck is removed. Leg correlation (see Correlations) is applied to multi-leg bets so true probability is estimated correctly rather than assuming independence.

Signal-generation pipeline (per strategy)

  1. Inputs — verified data: standings/net points, EPA, injury & depth status, market lines.
  2. Model line — originate our own line (spread / total / prop) from the model.
  3. Edge — compute model line vs. market line → edge and implied edge probability.
  4. Correlation — for multi-leg bets, attach measured leg correlation to price the combo honestly.
  5. Validation — run the strategy through all validation gates out-of-sample.
  6. Enroll — only if all gates pass, the strategy is admitted and ranked on the leaderboard.
Why all performance cells are blank. No strategy has yet been run against a full historical dataset and cleared the validation gates, so no ROI, hit rate, or CLV is published. Publishing an unvalidated number would reintroduce the very luck this system is designed to remove. These values will appear only after a strategy passes the gates — see Flagged for Review.
