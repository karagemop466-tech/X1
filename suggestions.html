Process principles this session recommends adopting

1. No edge without CLV. A strategy is only promoted to "validated" after beating the closing line on ≥100 logged picks (see gates). 2. Correlation is measured, never assumed — at game level we measured it (variance ratio 0.99); at player level it stays blocked until data exists. 3. Blank beats wrong. Unverifiable values stay blank and flagged. 4. Every table row cites its source. Verified values link to official pages; computed values link to the computing script. 5. Weekly cadence: data refresh → flags → model lines → picks logged pre-kickoff → scoring after close → digest.
