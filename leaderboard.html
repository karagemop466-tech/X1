Strategy Leaderboard — Competition

A competition in which strategies earn standing and rewards for top, validated performance. Only strategies that pass every validation gate are ranked. Performance is luck-adjusted so the ranking reflects skill.

Why the board is empty. No strategy has yet been run against a full historical dataset and cleared all seven validation gates. The board will fill only with validated results — no unvalidated or fabricated numbers are published. This is the same no-luck principle that governs the whole system.

How a strategy gets on the board

  1. Propose — a strategy is defined on the Strategies page.
  2. Run — it is executed over an out-of-sample historical window.
  3. Gate — each of the 7 validation gates is evaluated.
  4. Admit — only if all gates pass, the strategy is ranked and, if top-performing, rewarded.
  5. Publish — results and gate outcomes are published here and auditable.
