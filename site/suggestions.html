A dedicated place to review suggestions and choose a path before anything is implemented. Each suggestion lists three paths and a recommendation. Nothing here is built until the decision column says Approved.

How to use this page. Pick a row, read the three paths, then set decision_status and owner in data/suggestions.json ↗ (or ask for the change). The site republishes automatically on the next commit.

Decision workflow

  1. A suggestion enters as Proposed — awaiting decision.
  2. If it depends on an unanswered question it is additionally marked blocked by Q-nn and cannot be approved until that question is answered.
  3. A reviewer chooses a path (or writes a fourth) and records Approved — path X plus their name in owner.
  4. Only then is it implemented, and the row is updated to reflect what shipped.
  5. Anything rejected stays in the table with the rejection recorded, so the same ground is not covered twice.
