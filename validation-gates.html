Validation Gates

The pipeline every strategy must pass before it is admitted to the leaderboard or receives rewards. Each gate has explicit pass/fail criteria and is designed to remove a specific source of noise or bias — so that only skill, not luck, survives.

The rule. A strategy is not ranked, rewarded, or published until it passes all gates. A strategy that fails any gate is held out and reported on the Flagged for Review page. Thresholds are parameters to be set (see Open Question Q2); the structure is fixed.

Gate detail

G0 — Data integrity

Guards the inputs. A strategy built on unverified data cannot be trusted, so the first gate confirms provenance before anything else is evaluated. Unverified values must be blank and flagged, never inferred.

G1 — Minimum sample size

Guards against variance. A strategy with too few bets can look skilled purely by chance. The threshold is chosen so the confidence interval on edge is narrow enough to be meaningful (set per Q2).

G2 — Walk-forward / out-of-sample

Guards against look-ahead bias — the most common way simulated skill fails live. Training data must strictly precede test data, and every feature must be available at bet time (answers Q7).

G3 — Statistical significance

Guards against luck. Even a correctly specified strategy will have winning and losing streaks; this gate requires the edge to be statistically significant, not merely positive.

G4 — Closing-line value (CLV)

Guards against market-timing luck. Beating the closing line consistently is the accepted signal of genuine predictive skill; this gate requires sustained out-of-sample CLV.

G5 — Correlation & variance sanity

Guards multi-leg bets. Parlays and prop combos are only valid if leg correlation is measured and applied; assuming independence misprices risk (see Correlations).

G6 — Risk controls & reproducibility

Guards execution risk. Bounded sizing and drawdown limits prevent ruin; pinned data/code versions ensure any result can be reproduced and audited.

Effect. Together these gates separate a strategy that is genuinely skill-based from one that merely got lucky. Only strategies clearing all seven are ranked and rewarded on the leaderboard.
