Rules

1. Never start a task another session has claimed. 2. Keep file scopes non-overlapping. If you need a file another session owns, log the request here instead of editing it. 3. Small, frequent commits. Run git pull --rebase before every push. 4. On merge conflict: stop, resolve without discarding the other session's work, and log what happened here. 5. Never mark anything verified without checking it against an official source; record the source link. 6. If a session's claim is >60 minutes old with no commits, any other session may take over the task and note the handoff here. 7. Every table row on the site carries a source link to an official/trusted page. Values that cannot be confirmed are left blank and flagged as unverified — never inferred.
