Backtest set-up

  • Regular-season games from 2006 onward (where spreads exist in the source). Splits: discovery 2006–2015, validation 2016–2020, holdout 2021–2025 (scored once), forward 2026. Nothing was tuned on any split.
  • Spread convention: positive spread = home team favored; home covers if home margin is greater than the spread; equal is a push.
  • Pricing: −110 on both sides. Assumption, not verified against any book. Break-even 52.38%.
  • Own model: sequential Elo, updated after each game, using only earlier games. Constants fixed before testing: K = 20, home field = 65 Elo, 25 Elo per point, one-third reversion to 1500 each season. Edge threshold 3 points.
  • Multiple testing: Bonferroni across the 10 pre-registered strategies (conservative, because some strategies are mirrors of others).
  • Team codes: STL, SD and OAK are mapped to LA, LAC and LV for ratings only. The source uses ARI; NFL.com uses AZ (I-16).

Limits

  • Results depend on the line provider. Until it is verified, no result can be treated as evidence (G0), so none are published.
  • Historical game results are not checked game by game against NFL.com (I-11).
  • No injury, depth-chart, snap-count or player-prop data is used in the backtest yet.
  • Past performance on this data does not show future results.
