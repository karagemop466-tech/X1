What did not change, deliberately.
  • data/verify/raw/nfl_scores_2026_official.psv still prints 12 Week 10 games as SCHEDULED with blank scores, because that is what the official page said on 2026-11-14. The scores arrive in a dated overlay (data/verify/raw/nfl_scores_2026_official_promotions_2026_11_17.psv) so a backtest can join "what was printed" to "when it was read".
  • data/shadow/forecasts_pre_kickoff.csv is untouched. The scorer now reports the drift between the frozen record and today's model state instead of aborting the build that measures it.
  • data/results/verified_results_2026.csv remains the 137-row dated view: its builder reads only the verbatim anchor captures, and inventing newer anchors would destroy the property those files exist to have.
  • Published ROI still describes 137 modelled games, because the pipeline's model lines stop there (flag F-29, renumbered from PR #84's F-24 at integration). The grader now names the feed file it used on every row.
How to reproduce the whole closure. python3 tools/promote_week10_2026_11_17.py --check proves the appended rows still derive from this pack and that a re-run is a no-op; python3 tools/build_results_r3.py rebuilds the 150-game feed and its standings arithmetic; python3 tools/verify_2026_11_17_closure_473e08d5.py prints the nine checks.
