What is intentionally missing from this table

The official page prints additional columns whose meanings are not defined in its own legend (the legend only defines W, L, T, PCT, HOME, ROAD, DIV, CONF, PF, PA, NET PTS and STRK). Columns that the page does not explain are not transcribed, because guessing a column's meaning and then publishing it is exactly the failure mode this project is built to avoid.

Integrity checks applied to this table

  • 32 rows, 32 unique clubs, 8 divisions of exactly 4, ranks 1–4 appearing once per division.
  • Games played never exceeds 10 (the 2026 season is in Week 10).
  • PCT = (W + 0.5·T) / games for every club — this check is what caught the Arizona error.
  • NET = PF − PA for every club.
  • League-wide home wins = road losses, road wins = home losses, ΣW = ΣL, ΣT even, Σdiv W = Σdiv L, Σconf W = Σconf L.
  • Division and conference records are W–L–T triples; streaks match <n><W|L>.

A per-division home-record balance was tried and rejected: clubs play most games outside their division, so that identity is false. It was replaced, not weakened — the correction is recorded as D-02 in the repository review.
