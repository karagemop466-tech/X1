WORKSPACE / CROSS-CHECK SNAPSHOT 2026-11-14
VERIFICATION

Independent cross-check

Two sessions transcribed the same official NFL pages without coordinating. Where they agree, a typo is far less likely. This page reports the comparison — including the fact that it found nothing.

Why this page exists.

An arithmetic suite cannot catch a plausible but wrong number: this project's own Arizona error (2–6 instead of 3–6) was only caught because the win percentage happened to stop adding up. The real defence is a second independent transcription. One became available when another session merged its own read of the same official pages into main, so the comparison below is a genuine independent pass — not a self-review.

Two independent reads of the same pages agreeing on 1,604 values is meaningful evidence that the transcription is clean. It is not proof: two readers can make the same systematic error — reading the wrong column, or both trusting the same mislabelled header. That residual risk is recorded as flag F-13 and cannot be removed without a third source or the raw league data feed.

What was actually compared

standings : 32 clubs × (W, L, T, PF, PA, NET, PCT) = 224 comparisons injuries : 345 players × (position, injury, practice, game status) = 1,380 comparisons join key : (team, player) after normalising punctuation — e.g. “D.J.” vs “DJ”

One real difference, and what it teaches

The club key for the Rams differs between the two transcriptions: one writes LAR, the other LA. Both are used in the wild; neither is wrong. The comparison therefore normalises the alias explicitly rather than fuzzy-matching, because a fuzzy match on team codes is exactly the kind of shortcut that silently pairs the wrong rows. The alias is declared in tools/cross_check.py so a reviewer can see it and disagree with it.

Reproduce it

python3 tools/cross_check.py
