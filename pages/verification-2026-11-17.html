On the two clocks. Two clocks, and the difference between them is stated rather than smoothed. Each pack header carries a minute (22:45 / 22:48 / 22:52 UTC) that the READER wrote into the file at transcription time; the page reader itself returns content with no retrieval timestamp, so those minutes are a self-report, accurate to the order and the hour, not an instrument. The automated capture's stamp for the same standings page IS an instrument reading (2026-11-17T19:49:49Z, content sha256 in the header), and check B11 compares the two reads. The feed's arithmetic gate is validated against the dated pack; the capture is its second opinion. Where the brief asks for reads 'with a clock time', that is what the collector provides and what a hand read can only claim to the minute it noted itself.

Every check is arithmetic on a value an official page printed: standings identities (NET = PF − PA, PCT = (W + T/2)/GP, HOME + ROAD = W–L–T), league closure, three-page record agreement, corpus admission, the fingerprinted mirror as a cross-check, the sealed ledger re-derived at its own record time, the price-discipline rule, the forward slate's 13 + 6 = 32, and a second independent read of the standings page. No check reads a model output, so no model can validate itself.

What this pack does not check

  • injury / availability / depth tables and their day-over-day deltas — published by PR #73 (arena/16049865-x1) on the same date; this session deliberately did not touch that scope
  • the deficiency dataset's declared-column drift alarm — root cause handed to the drift owner and to PR #61 in COORDINATION.md (pipeline/run.py owns the payload's columns list)
  • player-level game books, snap counts and inactive lists — no licensed source in this repository
  • any price, closing line or ROI in dollars — no ratified price policy (Q-02)
