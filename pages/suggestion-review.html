Every suggestion, with the trade-off, before anything is built

Three registers are consolidated here. The research desk's list names the problem, the paths on the table and a recommendation. The site register adds a reversible first step for each proposal. The ranked board adds what each one answers and what it depends on. Nothing on any of them has been implemented automatically.

How to use this page. Pick by what it unlocks, not by what it looks like. Three proposals unblock the whole scoring layer and cost almost nothing; the rest improve how a reader can check the work. A suggestion that needs a decision from you before it can start is marked in its own row.

The five to look at first

  1. Name the price feed before any market column fills.

    Until one source is chosen as the benchmark, every price, edge and closing-line figure is undefined — and the four site trees disagree about which benchmark to use.

  2. Ratify the demotion thresholds.

    The gate that sends a live strategy back to paper is written but its numbers are not ratified, so nothing can be promoted safely.

  3. Publish the evidence grade on every row.

    It lets a reviewer apply a different trust threshold to a league fact than to a club self-report without reading the methodology each time.

  4. Run the second independent transcription pass.

    This session did exactly that for the 2026-11-19 read and it found one disagreeing cell and an unstable free-text column. That is the cheapest trust improvement available.

  5. Rank on signal only; keep staking in its own columns.

    A lucky staking run must never be able to mask a bad signal, and today the board shows both separately for exactly that reason.

What is explicitly not on this page

  • No suggestion is implemented because it was written. Each one waits for a decision, and the decision column says so.
  • No suggestion promises a number. A proposal that says it will “improve the model” is only credible with a measurement attached; the ones here name a count, a check or a file.
  • Two ideas have already been rejected and are kept on the record — deriving depth order from jersey number, and ranking strategies by season-long ROI. Both are published so they are not re-proposed.
