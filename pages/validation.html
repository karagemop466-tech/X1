METHOD / 02

Validation gates

Seven pre-registered gates a strategy must clear before it is scored, ranked or rewarded — in order, with no “but the ROI looks good” exception.

Pre-registered means written down before the test window opens. Moving a gate after seeing results is how strategy shops manufacture skill from noise.

The luck arithmetic, worked in the open

SE(p̂) = sqrt(p̂(1−p̂)/n) p_break(−110) = 110/210 = 0.5238 z = (0.551 − 0.5238)/sqrt(0.551·0.449/500) = 0.0272/0.0222 ≈ 1.22

z ≈ 1.22 is not skill. It is a coin landing 55 heads in 100. Gate 2 needs z ≥ 1.96 and a bootstrap 95% interval on ROI that excludes zero — both, not either. This single calculation is why a 55% record over a season cannot be sold as an edge.

Effective sample size for correlated tickets

n_eff = n / (1 + (k − 1)·ρ̄)

400 tickets averaging two shared legs with ρ̄ = 0.3 is effectively 308. The gate is held against n_eff, not the raw count, because correlated tickets are not independent draws.

Scoring rules that keep luck off the board

  • score only inside the registered window
  • passes are logged (a strategy with no denominator is invalid)
  • arithmetic (non-compounded) market return
  • report raw and top-5%-trimmed ROI together
  • champion requires two consecutive qualifying windows
  • two failed windows demote; no sitting on old results
  • challenger runs a full shadow window before displacing a champion
  • all entrants evaluated on identical frozen inputs

Ranking objective

score = z_skill - lambda*calibration_penalty - mu*drawdown_penalty

Weights: λ = 1.0, μ = 0.5. Report the components, never just the composite — a high score built on a large calibration penalty is a near-miss and must look like one.

Tie-breaks, in order: higher n_eff, lower calibration penalty, smaller max drawdown, earlier registration timestamp, alphabetical.
