Official club depth charts

Starters through 4th string, taken from each club's own website. This is the source that makes the deficiency watch possible: without knowing who is behind a starter, there is no way to say how badly an injury hurts a lineup.

Depth order is read left to right exactly as each club prints it: column 1 is the starter, column 2 the 2nd string, and so on. Where a club leaves a column empty, that slot simply has no player listed at that depth — which is itself a finding, not a gap to be filled.

Which domain counts as official

The pipeline does not guess club domains. It reads the league's own teams page ↗, which prints a "View Full Site" link to each club's official website, and uses whatever the league publishes there. The verified mapping is stored in data/club_registry.json and refreshed on every run.
