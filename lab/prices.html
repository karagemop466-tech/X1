Opening and closing numbers

Every market we originate, with the opening and closing snapshot kept apart and the missing fields counted rather than filled.

SNAPSHOT 2026-11-14 · WEEK 10
The structural finding, first. The only file that evidences an opening number covers 2021-2021; the only file that evidences a closing number covers 2006-2018. They never overlap, so 0 markets have both an opening and a closing number from a single publisher. No opening-to-closing move can be measured from this upstream.
