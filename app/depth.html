Why this is not a league fact

The league does not publish a depth chart. Each club publishes its own, and the formats differ: column counts range from three to four, position vocabularies differ (Baltimore uses RUSH / SAM / WLB / MLB, Chicago uses DL / LB / S / DB / CB, Green Bay uses EDGE / LB / NB / CB / S), and two of the clubs checked print either a stale date or an explicit "unofficial" disclaimer. Any statement of the form "the 2nd-string will replace him" is therefore a club self-report carried on this site with the club's own URL attached — never a league-verified fact.
