How to use this board

  1. Filter to pending. Those are the choices that have not been made.
  2. Read paths A, B and C. Each is a genuinely different way to solve the same thing — usually build-it, buy-it, or defer-it — with the cost and the risk written on the row.
  3. Pick one. The recommended column is a default, not a decision; it exists so that doing nothing is an explicit choice rather than an accident.
  4. Only then does the work start, and the row changes to decided with the owner recorded.

Nothing on this board has been built ahead of a recorded decision.
