How to use this section

1. Read the question

Each row states the information held and the information missing. A row marked BLOCKED has no answer that the current evidence can support.

2. Compare paths

The paths page keeps A, B and C separate with impact, effort, risk and what each unlocks. The recommendation is a reading aid, not a decision.

3. Record the choice

Write the chosen path in the blank Decision and Owner cells in data/suggestions/decision_center.json, then rebuild. Until then the site shows UNVERIFIED / AWAITING OWNER.

4. Only then implement

No path is implemented by this section. The one exception is the review surface itself, which the owner explicitly asked for.
