What this section adds

PageWhy it is not a duplicate
Verification ledgerThe published tables were verified by the sessions that wrote them. This session re-fetched each official page on 2026-11-14 and re-read the numbers without reference to the earlier result, then tested the official page against its own arithmetic before trusting any transcription from it. The method is different from the existing verify_against_official.py, which diffs the dashboard tables; this one counts the 28 club injury tables by hand and checks all 160 designated rows field by field.
FindingsTwelve items, two of which are values an official source actively contradicts rather than merely fails to support: Minnesota's expected quarterback, and Baltimore's. Neither is raised anywhere else on the site.
Depth deficiencyThe brief asks specifically which string — 2nd, 3rd or 4th — has to replace an out starter. This board answers that per position slot, and says so plainly for the eight slots where the club prints no replacement at all.
Suggestion review boardTwelve suggestions, each restated as a choice with two or three realistic paths, what each costs, what it unlocks, and which one is recommended. Nothing here is implemented — the point is to pick a path first.
The headline result of the re-verification. The published data holds up. Standings reconcile on 1,184 of 1,184 cells across three separate committed datasets; the injury report's 28 club tables count to 345 by hand, exactly as committed; all 160 rows carrying a game status match field by field; and the derived deficiency register's 66 affected starting slots all trace to a designation the league actually printed. What does not hold up is a small set of values that were inferred rather than read — mostly quarterback names — and they are on the findings page.
