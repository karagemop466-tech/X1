How this repository removes luck

  • G1 sets a floor of 200 settled out-of-sample bets, which is far below what the table says is needed for a small edge. That is deliberate: it is a floor, not a proof.
  • G3 requires a bootstrap 95% interval whose lower bound is above zero and an exact two-sided binomial p at or below 0.05 against the break-even rate.
  • G6 removes the games where luck is loudest — one-score games (margin of 3 or fewer) and blowouts (21 or more) — and requires the return to survive.
  • G7 refuses a threshold that only works at one setting. At least 60% of the neighbouring parameter values must also be positive, so a strategy cannot be promoted on a single lucky setting.
  • Signal is scored flat. One unit per bet, so a lucky run of large stakes cannot inflate the signal score.
What actually happened. No strategy passed. The best flat return on the board is -0.11% on 1,378 bets, and every neighbouring parameter setting was checked so that no single lucky threshold could carry a strategy through.
