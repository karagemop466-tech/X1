Read this before reading the table. The store is built and it records both ends, but no source available to this repository publishes an opening price for more than one season. The mirror carries exactly one number per market, with no book identifier and no capture timestamp. So: 1,072 of 18,902 rows hold both an opening and a closing number, and every one of them is 2021. Elsewhere the open column is blank by policy, not by omission. Filling it in would mean inventing a price.

How the store is populated

  • Markets originated now — the 156 markets on 2026 fixtures that carry a line and had not kicked off at the build date. The number standing at capture time is stored as the opening snapshot; the close stays blank until the game settles.
  • 2021 — the only season with a real opening number (nflverse/nfldata initial_lines.csv, sportsbook WSGT). Both ends exist, so a genuine opening-to-closing movement is published.
  • Everything else — one published number, stored as the close, with the opening column left blank.
