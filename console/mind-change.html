Every registered strategy states, in numbers, what would change its mind in each direction: 0 of 0 rules (0%) carry a confirm cell and a refute cell, and the checker fails the build if either cell contains no number.

“If the model gets better” is not a falsifier, and that is exactly what the first draft of this register contained: 6 of 16 rules were prose and had to be rewritten against a numeric standard before the checker passed. Each rule is allowed one refutation — meeting it retires the rule from the library instead of sending it back for a re-parameterisation, which is how a strategy survives by being tuned until it does.

With 16 rules judged on shared history, the per-family threshold is Bonferroni-adjusted to 0.05 / 16 = 0.003125, and the register carries that note beside every row so a rule that clears a gate by a hair cannot be presented as an independent result. The holdout column is the same for every rule: only the prospective escrow sample counts, because a backtest cannot promote anything.
